# Nexora

Nexora is a Flutter community directory for browsing a nine-member technology team. It combines Firebase email/password authentication with a responsive member directory, searchable profiles, favorites, category filters, and grid/list layouts.

## Features

- Firebase email/password sign-in and account registration
- Authentication gate that routes signed-in users to the directory
- Search members by name, role, or technical skill
- Filter by All, Tech & Systems, Design & QA, or Favorites
- Toggle between responsive grid and list views
- Mark members as favorites and view the favorites filter
- Member profile cards with role, skills, endorsements, and avatars
- Detailed profile view currently available for Mohamed Mahroos
- Light theme with Nexora navy, indigo, and cyan branding

## Tech stack

- Flutter (stable channel)
- Dart `^3.11.4`
- Firebase Core `^5.1.0`
- Firebase Auth `^7.0.1`
- Flutter Test and Flutter Lints

## Prerequisites

Install the following before running the project:

- Flutter SDK on the stable channel
- Dart SDK included with Flutter
- An Android emulator, iOS simulator, desktop target, or supported browser
- A Firebase project with Email/Password Authentication enabled

Verify the Flutter installation with:

```bash
flutter doctor
```

## Getting started

1. Clone the repository and enter the project directory.

2. Install dependencies:

   ```bash
   flutter pub get
   ```

3. Configure Firebase for the platforms you intend to run. The repository already contains generated FlutterFire configuration for Android, iOS, macOS, web, and Windows. If you use a different Firebase project, install the FlutterFire CLI and regenerate it:

   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```

4. In the Firebase console, enable **Authentication -> Sign-in method -> Email/Password**.

5. Run the app:

   ```bash
   flutter run
   ```

   To select a specific device, use `flutter devices` followed by:

   ```bash
   flutter run -d <device-id>
   ```

## Firebase notes

Firebase is initialized in `lib/main.dart` using the generated `DefaultFirebaseOptions` in `lib/firebase_options.dart`. Do not commit credentials or configuration for an unrelated Firebase project. When switching projects, rerun `flutterfire configure` and verify the platform-specific files generated by the CLI.

The app uses Firebase Authentication only; member records, favorites, and endorsement counts are currently defined locally in Dart and favorites reset when the app process restarts.

## Current limitations

- Only the Mohamed Mahroos profile has a dedicated biography screen wired into home navigation.
- The remaining member profiles currently fall back to the Mahroos biography screen until their own biography screens are implemented.
- Favorites and endorsement counts are local in-memory state and are not synchronized across devices or accounts.
- Linux Firebase options are not configured in the generated FlutterFire file.
